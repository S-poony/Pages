3. Description du Service

Pages est un outil permettant aux utilisateurs de convertir des fichiers locaux (PDF ou EPUB) en sites web statiques formatés comme des livres numériques.

  • Traitement : Le processus de conversion a lieu localement sur l'appareil de l'utilisateur.
  • Publication : Les utilisateurs peuvent choisir de publier le site web statique résultant sur le stockage Cloudflare R2 via l'interface Pages.
